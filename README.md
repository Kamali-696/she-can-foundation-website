## 📌 About the Project

This is the official website for **She Can Foundation**, a non-governmental organization registered under the **Indian Society Act, 1860**. The website serves as the digital presence of the foundation — sharing its mission, impact stories, team information, and providing a way for people to donate, volunteer, or get in touch.

She Can Foundation is dedicated to:
- 💜 Empowering women and girls across India
- 📚 Promoting access to education
- 🩸 Distributing free sanitary pads, awareness workshops, and dignity kits
- 🤝 Partnering with local organizations, governments, and communities

> The foundation has already reached **1,20,000+ girls** across India with free sanitary pads, awareness workshops, and dignity kits.

## 🚀 Getting Started

Since this is a plain HTML/CSS/JS project, there is no installation or build step needed.

### Option 1 — Open directly in a browser
Simply double-click `index.html` to open it in your default browser.

### Option 2 — Use a local development server (recommended)
For a better development experience (e.g., relative paths working correctly), use a simple HTTP server:

**Using VS Code:**
Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension, then right-click `index.html` → **"Open with Live Server"**.

**Using Python:**
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using Node.js:**
```bash
npx serve .
```
